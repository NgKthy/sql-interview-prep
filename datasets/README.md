# Sample CSV Datasets

Thư mục này chứa các file CSV mẫu để người dùng có thể import trực tiếp vào CSDL (MySQL, PostgreSQL, ...).

## Các file CSV:
- `employees.csv`: Dữ liệu mẫu nhân viên.
- `departments.csv`: Dữ liệu mẫu phòng ban.
- `orders.csv`: Dữ liệu mẫu đơn hàng.

## Hướng dẫn import:
Sử dụng script `scripts/import_csv.ps1` hoặc câu lệnh `LOAD DATA LOCAL INFILE` trong MySQL để import dữ liệu.
